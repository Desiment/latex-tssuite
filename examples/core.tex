This document loads \texttt{tssuite} without optional package features. The core
features are enumitem list presets and reusable text fields.

\section{List Presets}

The \verb|compact| key removes extra vertical spacing from ordinary lists.

\begin{itemize}[compact]
  \item State the claim.
  \item Prove the estimate.
  \item Record the dependency.
\end{itemize}

The \verb|widemargins| key gives lists more indentation, which can help when the
items are longer.

\begin{enumerate}[widemargins]
  \item Choose the normalization convention before writing the proof.
  \item Keep notation consistent between the statement and the examples.
  \item Move auxiliary calculations into a separate lemma when they are reused.
\end{enumerate}

\section{Text Fields}

Text fields store reusable document metadata. This example defines three fields
in the preamble and prints them in the table below.

\begin{table}[htbp]
  \centering
  \caption{Values stored through \texttt{tssuite} text fields}
  \begin{tabular}{ll}
    \toprule
    Field & Value \\
    \midrule
    Course & \PrintTextField{course} \\
    Owner & \PrintTextField{owner} \\
    Status & \PrintTextField{status} \\
    \bottomrule
  \end{tabular}
\end{table}

Field setters can be called again to update a value.

\DocumentStatus{reviewed}

The document status is now \PrintTextField{status}.
